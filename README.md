# Edit Wherever

Your video studio, wherever you are. By Wealthy Wherever.

## Install
In the Claude desktop app, open the **Code** tab and paste these two lines, one at a time:
```
/plugin marketplace add wealthywherever/studio
/plugin install edit-wherever@wealthywherever
```
Then say **"open my studio"**. Your key is in your purchase email.
